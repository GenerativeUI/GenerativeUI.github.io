How the Algorithm Works

Breadth First Search (BFS)

BFS explores the maze layer by layer. It guarantees the shortest path by visiting all nearby cells before moving deeper.

Understanding the logic behind the solution

This section explains how each algorithm approaches the maze step by step.

Use this explanation to compare algorithms and build intuition around time and space complexity.

solver.js BFS 

function BFS(start, end) {
  const queue = [start];
  const visited = new Set([start]);

  while (queue.length) {
    const cell = queue.shift();
    if (cell === end) break;

    neighbors(cell).forEach(n => {
      if (!visited.has(n)) {
        visited.add(n);
        n.parent = cell;
        queue.push(n);
      }
    });
  }
}

BFS vs DFS

Both algorithms explore mazes differently. Understanding their trade-offs helps explain why one finds the shortest path while the other explores faster.

Property BFS DFS
Path optimality Always shortest Not guaranteed
Exploration pattern Layer by layer Depth first, then backtrack
Memory usage Higher (stores frontier) Lower (stack based)
Speed in large mazes Slower Often faster
Completeness Guaranteed to find solution Yes (if no infinite paths)
Best use case When shortest path matters When exploration speed matters
Disclaimer: In this visualizer, BFS guarantees the shortest route, while DFS demonstrates deep exploration behavior.

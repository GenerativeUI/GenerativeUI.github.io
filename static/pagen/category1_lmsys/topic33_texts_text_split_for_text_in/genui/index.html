from collections import Counter

texts = [text.split() for text in df["text_processed"]]

# --- Optimized Vocabulary ---
# Set comprehension is faster and cleaner
wordsList = sorted(list({word for text in texts for word in text}))

# 1. Create a Lookup Table (Hash Map) -> O(1) Access
word2id = {w: i for i, w in enumerate(wordsList)}

with open("./new_ap/vocab.txt", "w") as f:
    f.write("\n".join(wordsList) + "\n")

# --- Fast Data Writing ---
with open("./new_ap/ap.dat", "w") as f:
    for text in texts:
        # 2. Counter scans text ONCE -> O(N)
        counts = Counter(text)
        
        # Standard sparse format: unique tokens only
        line_data = []
        for word, count in counts.items():
            if word in word2id:
                idx = word2id[word]
                line_data.append(f"{idx}:{count}")
        
        f.write(f"{len(line_data)} {' '.join(line_data)}\n")

Why was the original code slow?

search

Linear Search O(N)

wordsList.index(word) scans the entire vocabulary list item by item until it finds the word. If you have 10,000 words, it checks up to 10,000 items every single time you process a word.

repeat

Redundant Counting O(N²)

text.count(word) re-scans the entire document text to count occurrences. Inside a loop that already iterates through the text, this creates a "nested loop" effect, leading to quadratic time complexity.

lightbulb

The Solution

By using a Dictionary (Hash Map), we get O(1) instant lookups for indices. By using Counter, we count all words in a single pass. This reduces the time from hours to seconds.

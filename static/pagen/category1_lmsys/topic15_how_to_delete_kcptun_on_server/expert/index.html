How to Safely Remove kcptun from a Server

A step-by-step guide to completely uninstall kcptun from your server environment

🔹 Introduction

kcptun is a tool that improves network performance by tunneling traffic with KCP. While it's powerful, you may want to remove it if you:

  • No longer use it
  • Are switching to another tunneling solution
  • Need to free up server resources

🔹 Step-by-Step Removal Process

  1. Stop the kcptun Service

    If kcptun is running as a system service:

    sudo systemctl stop kcptun
    sudo systemctl disable kcptun

    Or if it's running in the background manually:

    pkill kcptun

  2. Remove kcptun Files

    Typically, kcptun binaries are placed in /usr/local/bin/ or your installation directory. To remove:

    sudo rm -f /usr/local/bin/server_linux_amd64
    sudo rm -f /usr/local/bin/client_linux_amd64
    (Replace with your actual binary names)

  3. Delete Configuration Files

    Configs are usually in /etc/kcptun/ or wherever you saved them. Remove with:

    sudo rm -rf /etc/kcptun

  4. Verify Removal

    Check if kcptun is still running:

    ps aux | grep kcptun

    If nothing shows up (other than the grep line), it's gone ✅

🔹 Alternative Cleanups

If installed with a script: re-run the uninstall option if provided.

If running in Docker:

docker stop kcptun
docker rm kcptun

🔹 Closing Note

Removing kcptun is straightforward — just stop the service, delete binaries and configs, and verify. Always double-check you're not deleting other important files.

🔎 What is Cypher Query Language?

The powerful query language for Neo4j and graph databases.

Introduction

Cypher Query Language (CQL) is the declarative query language used to interact with Neo4j, a popular graph database.

It's designed to make working with connected data intuitive and expressive.

Instead of rows and columns, Cypher deals with nodes (entities) and relationships (connections).

Why Cypher?

🧩

Simple Syntax

Uses ASCII-art-like patterns to represent nodes and relationships.

(Alice)-[:FRIEND]->(Bob)
🚀

Efficient

Optimized for traversing large, complex networks.

MATCH (a)-[*1..3]-(b)
🌍

Real-World Modeling

Great for social networks, recommendation engines, fraud detection, etc.

(:User)-[:LIKES]->(:Product)

Core Concepts

Nodes

Represent entities (e.g., a person, product, or place)

Creating a Node 
CREATE (p:Person {name: "Alice"})

Relationships

Show how nodes connect

Creating a Relationship 
MATCH (a:Person {name: "Alice"}), (b:Person {name: "Bob"})
CREATE (a)-[:FRIEND]->(b)

Queries

Ask questions about the graph

Finding Relationships 
MATCH (a:Person)-[:FRIEND]->(b:Person)
RETURN a.name, b.name
a.name b.name

Fun Facts

📌

Cypher was inspired by SQL, but optimized for graphs.

📌

It powers not just Neo4j, but also the openCypher project — making graph databases more accessible.

📌

Neo4j chose the name "Cypher" because of its connection to patterns and codes.

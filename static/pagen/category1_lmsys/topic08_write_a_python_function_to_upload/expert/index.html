💻 Upload All Files from a Local Folder to S3 with Python

A simple Python script using boto3 to upload an entire folder into an Amazon S3 bucket.

Requirements

1) Python 3.x 2) boto3 library installed 3) AWS credentials configured (via aws configure or environment variables).
Installation Command 
pip install boto3

Python Function

Python Code 
import os
import boto3

def upload_folder_to_s3(local_folder, bucket_name, s3_folder):
    """
    Uploads all files from a local folder to a specific S3 bucket directory.
    
    :param local_folder: Path to your local folder
    :param bucket_name: Name of your S3 bucket
    :param s3_folder: S3 folder path where files should be uploaded
    """
    s3 = boto3.client('s3')
    
    for root, dirs, files in os.walk(local_folder):
        for file in files:
            local_path = os.path.join(root, file)
            relative_path = os.path.relpath(local_path, local_folder)
            s3_path = os.path.join(s3_folder, relative_path).replace("\\", "/")
            
            print(f"Uploading {local_path} to s3://{bucket_name}/{s3_path}")
            s3.upload_file(local_path, bucket_name, s3_path)

Example Usage

Usage Example 
upload_folder_to_s3(
    local_folder="my_local_data",
    bucket_name="my-s3-bucket",
    s3_folder="backups/2025"
)

✅ This will upload everything in my_local_data/ into s3://my-s3-bucket/backups/2025/.

Common Errors

Permissions Issues

Ensure your IAM user has the necessary s3:PutObject permissions to upload files to the S3 bucket. Check both the bucket policy and IAM user permissions.

Missing Credentials

AWS credentials must be configured either via the AWS CLI or environment variables for boto3 to authenticate. Verify your credentials are set correctly.

Bucket Doesn't Exist

Verify that the S3 bucket name you're trying to upload to actually exists in your AWS account and is in the correct region.

Network Connectivity

Check your internet connection and ensure you can reach AWS S3 endpoints from your network. Firewall rules may be blocking the connection.

Notes

Important Considerations

Make sure your IAM user has s3:PutObject permissions.

boto3 will automatically handle large files with multipart upload.

For large folders, consider adding error handling and retry logic for failed uploads.

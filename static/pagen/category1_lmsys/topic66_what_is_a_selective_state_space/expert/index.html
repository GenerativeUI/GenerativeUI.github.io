The Selective Mechanism

Unlike traditional State Space Models with fixed parameters, Selective SSMs dynamically adjust their behavior based on input content

Input Processing

All tokens processed equally

Parameter Behavior

Matrix A Diagonal Values
Selection Parameters (Δ, B, C)
Δ, B, C = constant - Fixed values
Traditional SSM Issues
  • • Fixed parameters for all inputs
  • • Cannot focus on relevant information
  • • Limited modeling capacity
  • • Poor performance on complex tasks
Selective SSM Advantages
  • • Input-dependent parameter selection
  • • Focus on important information
  • • Better modeling of complex dependencies
  • • Competitive with Transformers

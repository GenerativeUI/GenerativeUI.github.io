📚 Types of Equations

Explore different types of mathematical equations, their characteristics, and real-world applications

Linear Equations

First-degree equations with variables raised to the power of 1

General Form:
ax + b = 0
Example:
2x + 5 = 13
Solution:
x = 4
💡 Applications
→ Distance calculations
→ Rate problems
→ Simple interest
→ Break-even analysis

Quadratic Equations

Second-degree equations with variables raised to the power of 2

General Form:
ax² + bx + c = 0
Example:
x² - 5x + 6 = 0
Solution:
x = 2 or x = 3
💡 Applications
→ Projectile motion
→ Area optimization
→ Parabolic paths
→ Profit modeling

Systems of Equations

Multiple equations with multiple variables solved simultaneously

General Form:
{ax + by = c, dx + ey = f}
Example:
{2x + y = 7, x - y = 2}
Solution:
x = 3, y = 1
💡 Applications
→ Supply and demand
→ Mixture problems
→ Investment planning
→ Resource allocation

Quick Tips for Solving Equations

1

Isolate the Variable

Use inverse operations to get the variable by itself on one side

2

Keep It Balanced

Whatever you do to one side, do the same to the other side

3

Check Your Answer

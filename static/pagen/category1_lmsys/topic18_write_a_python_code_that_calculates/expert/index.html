Write a Python Code That Calculates the Sum of 5 and 10

Experience live Python coding with animations!

🔹 The Task

We want a simple Python program that adds two numbers — 5 and 10 — and shows the result.

🔹 The Code

# Simple Python program to add two numbers
a = 5
b = 10
result = a + b
print("The sum of", a, "and", b, "is:", result)
🎯 🔹 Output: The sum of 5 and 10 is: 15

🔹 Explanation

  • We define two numbers: a = 5 and b = 10
  • We add them together: result = a + b
  • We print the result using the print() function

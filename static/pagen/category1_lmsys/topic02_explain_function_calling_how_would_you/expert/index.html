💻 What Does It Mean to "Call a Function"?

Functions are like reusable machines in code — you give them inputs, they do some work, and return an output. "Calling a function" is how you make that machine run.

👉 Try Calling a Function

What is a Function?

A function is a reusable block of code designed to perform a specific task. Functions help break our program into smaller, modular chunks for better organization and maintenance.

Input
Function
Output

Why Use Functions?

  • Code Reuse: Write once, use multiple times
  • Organization: Break complex problems into smaller pieces
  • Abstraction: Hide implementation details
  • Maintenance: Easier to debug and modify

How to Call a Function

Calling a function means telling your program: run this code now with these inputs. You call a function by using its name followed by parentheses.

General Syntax

functionName(argument1, argument2, ...);

JavaScript Example

function greet(name) {
  return "Hello, " + name + "!";
}

// Calling the function
let message = greet("Alice");
console.log(message); // Output: "Hello, Alice!"

Python Example

def greet(name):
  return f"Hello, {name}!"

# Calling the function
message = greet("Alice")
print(message) # Output: "Hello, Alice!"

What Happens When You Call a Function?

When you call a function, the program follows a specific sequence of steps:

1

Inputs (Arguments)

The values you pass to the function are received as parameters.

2

Execution

The function's code runs line by line with the provided inputs.

3

Return Value

The function sends back a result (if specified) to where it was called.

Different Kinds of Function Calls

No Arguments

function sayHi() {
  return "Hello there!";
}

let greeting = sayHi(); // No arguments passed

With Arguments

function add(a, b) {
  return a + b;
}

let result = add(2, 3); // Arguments: 2 and 3

Nested Calls

function square(x) {
  return x * x;
}

function add(a, b) {
  return a + b;
}

// Nested function call
let result = square(add(2, 3)); // square(5) → 25

Recursive Calls

function factorial(n) {
  if (n <= 1) {
    return 1;
  } else {
    return n * factorial(n - 1); // Recursive call
  }
}

let result = factorial(5); // 5! = 120

How it works — Python solutions

Robust and edge-case friendly

Below are several patterns you can use depending on file size and needs: simple split, line-based state machine (recommended), regex-based split, streaming generator for very large files.

1) Recommended — line-based parser (handles spacing, empty items) 
def parse_questions_lines(path):
    questions = []
    cur = []
    with open(path, 'r', encoding='utf-8') as f:
        for raw in f:
            line = raw.strip()
            if line == '-':
                # separator -> flush current question if non-empty
                q = '\\n'.join(cur).strip()
                if q:
                    questions.append(q)
                cur = []
            else:
                cur.append(raw.rstrip('\\n'))
    # final flush in case file doesn't end with '-'
    final = '\\n'.join(cur).strip()
    if final:
        questions.append(final)
    return questions
2) Simple split on separator lines (works for smaller files) 
def parse_questions_split(path):
    text = open(path, 'r', encoding='utf-8').read()
    # normalize CRLF, then split on newline + '-' + newline (allowing surrounding spaces)
    import re
    parts = re.split(r'\\r?\\n\\s*-\\s*\\r?\\n', text.strip())
    return [p.strip() for p in parts if p.strip()]
3) Generator for streaming (large files) 
def parse_questions_stream(path):
    def gen():
        cur = []
        with open(path, 'r', encoding='utf-8') as f:
            for raw in f:
                line = raw.strip()
                if line == '-':
                    q = '\\n'.join(cur).strip()
                    if q:
                        yield q
                    cur = []
                else:
                    cur.append(raw.rstrip('\\n'))
        if cur:
            final = '\\n'.join(cur).strip()
            if final:
                yield final
    return list(gen())

Tips: make sure separators are on their own line; watch for trailing separators (they'll be ignored). Use encoding='utf-8' for modern files.
